# Q3009-course
Material for the Q3009 course
The purpose of this repository is to support the implementation of the undergraduate course Biostructure Modeling-Q3009.
Software requirements: open-source VMD-Visual Molecular Dynamics.

The sequence of files in this respository aims at reproducing, as much as possible, 
the structure of the course at the Moodle platform of the University of Porto
(http://moodle2526.up.pt/course/view.php?id=5710).
